实现与规划

展开查看范围与接口。

实现范围

当前实现包含 API 网关、显式模型映射、调度策略、健康管理、流式转发、追踪与聚合指标。扩缩容接口与 PD 路由属于调度边界；具体部署组合单独验证。

与 Engine 的接口

Control Plane 读取实例健康、负载与容量信息，下发请求并接收状态。Engine 负责 token 执行、KV 管理和数据传输。

与 Continuum 的接口 · 规划

应用可从 Continuum 取得任务状态和相关记忆，组织为模型输入，再交给服务入口。记忆持久化与版本管理由 Continuum 承担。
