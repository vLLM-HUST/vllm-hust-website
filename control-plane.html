第八版引擎与请求限流控制器的配对实测Paired measurements with Engine r8 and Request Throttling Controller

2026-11-18，RIDE 在独立 CPU 工作区启动请求限流控制器实例，连接独立运行的第八版引擎。实际托管的实例处理了 336 个请求，随后由 RIDE 停止。实测报告记录了与直连引擎的三轮轨迹回放对照，以及完整批次耗时。On November 18, RIDE launched a Request Throttling Controller instance in a separate CPU workspace and connected it to an independently running Engine r8. The managed instance handled 336 requests and RIDE stopped it after the run. The results page provides the batch times from the paired three-turn replay against direct engine access.

管理面、执行层与推理引擎Management, execution and inference

RIDE 持有作业身份、管理启停并记录状态。Ray 执行独立控制器和模型作业。推理请求由所选服务入口转发至引擎，RIDE 管理接口用于部署和运维。RIDE tracks job identity, lifecycle and status. Ray executes independent controllers and model jobs. Inference flows from the serving endpoint to the engine, while RIDE’s management API handles deployment and operations.
