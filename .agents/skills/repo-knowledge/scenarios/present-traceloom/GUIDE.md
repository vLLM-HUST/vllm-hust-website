# Present TraceLoom analysis and runtime observation

TraceLoom is a peer MOD to BetterScale, not a homepage feature or leaderboard submission.
`traceloom.html` owns the bilingual explanation. The catalog's `traceloom` runtime component is an
opt-in scheduler observer with a standalone native analyzer; do not erase either entry point. Its
package is `traceloom`, including the native CLI and Python API plus the `traceloom-vllm-context`
dependency. Do not regress to requiring two manual installations.

The website mirrors classification from the docs repository's declared canonical branch,
`codex/ecosystem-architecture-reorganization`, registry files. Add only TraceLoom's entry and
portfolio association; do not overwrite unrelated newer website facts from that older registry
snapshot. There was no local knowledge tree in that checkout; the global cultivate skill planted its
starter.

Scheduler-only injection is patch-free; execution-linked capture requires the explicit
transport/worker patch. Neither route is an Extension Manager bundle. Keep the eager and graph Qwen
qualifications separate from distributed support, instrumentation overhead and speedup claims. Graph
replay is a core analyzer capability, not just an opaque scheduler label. Stage-constrained grammar
and YAML-marked model structure are currently separate projection routes.

`assets/traceloom-capture.svg` is a real-time-coordinate projection of the first four nonempty steps
in the approved Qwen capture, not a mechanism sketch. `data/traceloom-capture.json` contains only
those displayed intervals: no prompts, request identities or bulk raw trace. Step bars are
associated-device envelopes, not busy time or complete membership. Never regroup bodies by
repeat-context labels across concrete instances; this formerly drew N057 across multiple steps.

Run `scripts/verify_traceloom_browser.py` against a local static server, then the website test suite
and pre-commit checks. Verify both languages and desktop/mobile widths. Shared site CSS makes bare
section headings white: the light TraceLoom surface needs scoped heading colors. Popup visibility is
animated; use Playwright retrying assertions with `use_inner_text=True`, not an immediate inner_text
read.

The 0.1.1 page adds bounded graph acceptance from analyzer commit `5c5ab88`: 30 decode replays / 30
supplied steps / 339 exact members each (10,170 total), 369 internal pattern occurrences unchanged
by step partitioning, no non-root cross-step occurrence. Source conditions and audit are in the
analyzer's `docs/runtime-context.md`. The existing SVG and its numeric cards still describe the
separate eager capture; do not relabel that image as graph evidence.

Official torch-npu graph reconstruction needs the original capture directory and parsed
capture-stream mapping, not merely its exported monolithic DB. Scheduler-only injection still cannot
provide step/device identity. Preserve these distinctions when presenting the now-supported
step/replay integration.
