Quality, formulas and original evidence

All four services completed: 800 successful responses to the same 200 fixed questions. Correct: 145 → 147/200 forward, 148 → 146/200 reverse. Truncated: 21 → 20 and 20 → 20.

The same 200 questions are submitted together at an infinite request rate, with the original 8192-token answer budget, EOS, seed 0 and 194 common unscored warmups. Throughput is all generated tokens divided by the full cohort wall time. Mean TTFT includes queueing for all 200 requests; TPOT uses each response’s time after its first token divided by completion tokens minus 1.

Historical C15 internal screens: throughput ≥ +10%; mean TPOT ≤ +2%; mean TTFT and each P95/P99 ≤ +5%; correct ≥144/200; truncated ≤22; all200 responses complete. Original outcomes remain unchanged; these internal screens are separate from project acceptance targets.
