# B0/B1 页面结论与文案

页面按大纲逐项给出本轮结论、数值和依据。阶段门槛、测量条件和实际范围均沿用 benchmark 发布源。

- 有效测量达到对应门槛，写“达标”，同时标明工况。
- 测得结果低于门槛，写“未达标”，列出数值和门槛。
- 验收所需计量条件或任务范围缺失，写“未通过”，紧接具体缺项。缺失值保持缺失，不补成零或构造效率。
- 区分实测有效算力、模型诊断效率和正式效率；模型诊断使用自己的名称与来源。
- 批次性能、长上下文窗口、任务稳定性、租赁估算分别判断。旧配置记录保留其身份，不覆盖为新配置结果。
- 对租赁估算明确费用范围、折算天数、请求分母和资源占用；页面不把公开报价写成实际账单。
- 直接写条件与结果，删除“修订中”“尚不能判定”“未闭合”等悬置措辞，以及反复自辩。细节通过原始记录链接提供。
- 中英文同步，验收最终公开页面的数值、结论、来源、窄屏布局和错误数据拒绝行为。页面结论不是第三方验收签署。

测量、成绩、配置元数据与原始报告只维护在 benchmark。网页从固定提交读取，并保留 SHA256 校验。
