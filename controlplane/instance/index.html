真实模型扩缩容验证Model service scaling verification

实例控制器发起扩容，RIDE 启动准确的模型作业；新实例就绪后接收流量。缩容时先停止向目标实例分配新任务，等待在途请求和缓存动作排空，再由 RIDE 停止该作业。The Instance Controller initiates scale-up and RIDE starts the specific model job. The new instance receives traffic once ready. Scale-down stops new assignments, waits for requests and cache operations to drain, and then stops that job.

路线图记录了真实生成和扩缩过程。这项功能验证覆盖固定测试环境，跨物理主机、真实缓存迁移和性能收益各有独立验收。The roadmap records real generation and scaling in the test environment. Cross-host operation, real cache migration and performance gains have separate acceptance criteria.
